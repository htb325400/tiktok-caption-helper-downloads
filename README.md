# TikTok 字幕助手

提取字幕、识别语音、翻译内容，在视频旁查看带时间轴的原文与译文。

这是插件的**公开介绍与下载仓库**，不包含开发源码仓库、测试及内部研发资料。开发仓库已设为私有。安装包包含浏览器运行所需的 JavaScript，仍可被用户检查；不承诺代码不可查看。

## 下载

前往 [最新版本下载页](https://github.com/htb325400/tiktok-caption-helper-downloads/releases/latest)，下载 `tiktok-caption-helper-0.9.24.zip`，然后按 [安装说明](INSTALL.md) 操作。

当前版本：**0.9.24 · 实验版**。不是 Chrome 网上应用店安装包，也不支持自动更新。

## 能做什么

- 提取 TikTok 页面已有字幕。
- 通过 Groq Whisper 识别缺少字幕的视频语音。
- 展示时间轴、原文与译文，支持复制字幕。
- 提供 Google、GPT 兼容网关、DeepSeek 和豆包翻译入口。
- 提供视频下载及页面截图操作。
- 设置页不再提供 Gemini 配置；数据采集功能未开放。

## 如何开始

1. 下载 ZIP 并解压，加载到 Chrome。
2. 打开 `www.tiktok.com` 视频页面，打开扩展设置。
3. 选择翻译服务与目标语言。
4. 如果需要语音识别，保存自己的 Groq API Key。
5. 点击“开始翻译”；页面面板中“翻译”用于翻译已有原文，“识别”用于重新识别。

## 使用边界

- 插件目前重点支持 TikTok 页面，不是通用网页翻译器。
- ASR 和翻译可能出错，原文候选和译文需要人工判断；时间轴按已有字幕或识别结果展示。
- AI 翻译失败时保留原文并提示，不静默切换 Google。
- DeepSeek/豆包独立配置隔离尚未完成，不能把服务入口当作已完整验收的功能。
- 本地回归测试 748/749 通过，已知失败为 DeepSeek 独立配置测试；没有因此声称真实浏览器、网关连通性或准确率已通过。
- 只处理你有权访问和使用的内容，遵守平台及服务条款。
